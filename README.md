## গজল (audio) — GitHub / Google Drive থেকে অটো আপডেট
অ্যাপ গজল পেজ খুললে (এবং অ্যাপে ফিরে এলে) নিজে থেকেই অনলাইন ফোল্ডার দেখে তালিকা আপডেট করে। নতুন অ্যাপ বিল্ড লাগে না।
অফলাইনে শেষবারের তালিকা দেখায়।

**GitHub (সবচেয়ে সহজ)**
1. রিপো **Public** রাখো। অডিও (mp3/m4a/aac/wav/ogg/opus/flac) রিপোর `gazal/` ফোল্ডারে আপলোড করো।
2. অ্যাপে গজল পেজ → ☁️ আইকন → "GitHub রিপো" ঘরে লেখো `তোমার-নাম/রিপো-নাম`
   (অন্য ফোল্ডার হলে `তোমার-নাম/রিপো-নাম/ফোল্ডার`)।
3. এরপর শুধু নতুন ফাইল আপলোড করলেই হবে। ফাইলের নামই গজলের নাম (`_` বদলে স্পেস হয়)।
- অ্যাপে সবার জন্য আগে থেকে সেট করতে `lib/config.dart` এ `kGazalGithub` লিখে দাও।

**Google Drive**
1. ফোল্ডারে অডিও রাখো, Share → "Anyone with the link – Viewer"।
2. Google Cloud Console এ Drive API চালু করে একটি API key বানাও।
3. অ্যাপে ☁️ আইকন → ফোল্ডারের লিংক (বা ID) ও API key দাও।

**ফোন থেকে যোগ**: `+` বাটন দিয়ে এখনও ফোন থেকে mp3/m4a যোগ করা যায়।
**অ্যাপের ভেতরে বান্ডেল**: `assets/audio/` এ ফাইল রেখে `assets/gazal.json` এ লেখো:
`[{"title": "গজলের নাম", "artist": "শিল্পী", "asset": "audio/file.mp3"}]`

## ভাষা
মেনু ট্যাবের উপরের 🌐 বাটন বা প্রোফাইল → "ভাষা" থেকে বদলানো যায়: বাংলা, English, العربية, اردو, हिन्दी, Türkçe, Bahasa Indonesia, Bahasa Melayu।
আরবি/উর্দুতে লেআউট ডান-থেকে-বামে হয়। নতুন ভাষা যোগ করতে `lib/i18n.dart` এ `kLangs` এ কোড যোগ করে প্রতিটি লাইনের শেষে একটি অনুবাদ বসাও
(ক্যালেন্ডারের নাম `lib/features/calendar_util.dart` এ)।

## স্লাইড ব্যানার
ব্যানারে ট্যাপ করলে মেনুর একটি ফিচার খোলে। কোনটা কোথায় যাবে `lib/main.dart` এর `_banners` এ ঠিক করা আছে
(ফিচার id: quran, hadith, prayer, tilawat, kitab, gazal, qshikkha, dua, quiz, amal, ai, bibaho)।

## রেজিস্ট্রেশন, লগইন ও প্রোফাইল
- অ্যাপ খুললে প্রথমে **রেজিস্ট্রেশন** পেজ আসে (নাম, ইমেইল, ফোন, পাসওয়ার্ড) অথবা **গুগল দিয়ে চালিয়ে যান**।
- রেজিস্ট্রেশনের পর প্রোফাইল ট্যাব → **প্রোফাইল সম্পাদনা** থেকে নাম/ফোন বদলানো যায়। প্রোফাইল ট্যাবের নিচে **লগআউট** আছে।
- অ্যাকাউন্টের তথ্য শুধু এই ফোনে থাকে (পাসওয়ার্ড hash করা)। সার্ভার নেই, তাই অন্য ফোনে একই অ্যাকাউন্ট পাওয়া যাবে না।

### Google Login চালু করার সেটআপ (একবার)
1. <https://console.cloud.google.com> এ প্রজেক্ট খোলো → **APIs & Services → OAuth consent screen**: External, অ্যাপের নাম দাও। Testing অবস্থায় থাকলে **Test users** এ যাদের ইমেইল দিয়ে লগইন করবে সেগুলো যোগ করো (বা Publish করো)।
2. **Credentials → Create credentials → OAuth client ID → Android**:
   - Package name: `com.noor.noor_app`
   - SHA-1: `2E:55:E7:A0:D2:26:03:29:24:76:83:A3:90:36:17:34:43:22:2E:11`
3. হয়ে গেলে নতুন APK বিল্ড করে ইনস্টল করো। কোড বদলানোর দরকার নেই।
- `signing/debug.keystore` রিপোতে রাখা আছে এবং বিল্ডে ব্যবহার হয়, তাই প্রতিবার SHA-1 একই থাকে। এটা ডিবাগ কী, Play Store এ দেওয়ার সময় আলাদা release key বানাতে হবে।
- লগইনে `ApiException: 10` এলে SHA-1 বা package name মেলেনি; `12500` এলে consent screen বা Test user সেটআপ বাকি।

### অ্যাপ আপডেট দেওয়ার নিয়ম
1. `pubspec.yaml` এ `version:` বাড়াও (যেমন `1.0.0+1` → `1.0.1+2`), কোড GitHub এ push করো।
2. Actions বিল্ড শেষে নিজে থেকে **Releases** এ `v1.0.1` নামে APK প্রকাশ করে।
3. ফোনে অ্যাপ → সেটিংস → **অ্যাপ আপডেট**। নতুন ভার্সন থাকলে "ডাউনলোড ও ইনস্টল" চাপলে APK নামে, ইনস্টল করলেই আপডেট।
- প্রথমবার রিপোর নাম (`owner/repo`) জিজ্ঞেস করবে, অথবা `lib/config.dart` এর `kUpdateGithub` এ লিখে দাও। রিপো **Public** হতে হবে।
- আপডেট ইনস্টল হবে কারণ প্রতিবার একই `signing/debug.keystore` দিয়ে সাইন হয়। ব্রাউজারকে প্রথমবার "unknown apps ইনস্টল" এর অনুমতি দিতে হতে পারে।
